# RFP Proposal Platform

## Project Overview
Local RFP and proposal generation platform built on self-hosted Mistral 7B (via Ollama). Uses a Plan-Execute agentic architecture where a supervisor LLM makes all routing, planning, and termination decisions at runtime.

## Tech Stack
- **Language:** Python 3.10+
- **Framework:** FastAPI (backend), Streamlit (UI)
- **LLM:** Mistral 7B Instruct via Ollama (`http://localhost:11434`)
- **Database:** PostgreSQL with pgvector for embeddings
- **Task queue:** Celery + Redis
- **Embeddings:** sentence-transformers/all-MiniLM-L6-v2 (384-dim)
- **Fine-tuning:** LoRA/QLoRA via PEFT + TRL
- **Retrieval:** FAISS index + pgvector RAG
- **Config:** pydantic-settings with `RFP_` env prefix, `.env` file

## Architecture
- **Agentic runtime** (Plan-Execute with replanning): supervisor LLM picks intent, makes a plan, runner executes tools, supervisor replans on failure, supervisor confirms done.
- **Orchestrator** is a thin shim — every endpoint calls `run_agentic()` with an intent hint and reshapes results.
- **Agents** are unchanged from pre-agentic era; they're exposed as tools via `agentic/tools.py`.
- Compound tool `generate_proposal_sections` batches retrieve+generate+validate per section to limit supervisor calls on slow local Mistral.
- Heuristic fallbacks in supervisor keep the system alive when LLM fails to produce valid JSON.
- Budget: max 12 tool calls, max 2 replans per workflow.

## Key Endpoints
- `POST /api/workflow-runs` — proposal generation
- `POST /api/generated-sections/{id}/revise` — revision
- `POST /api/document-match-runs` — document matching
- `POST /api/market-research-runs` — market research
- `POST /api/intent-detection-runs` — intent detection

## Development
```bash
# Setup
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# Run API server
uvicorn main:app --app-dir src --reload

# Run Streamlit UI
streamlit run ui/app.py

# Requires running services
# - Ollama with mistral:latest pulled
# - PostgreSQL on localhost:5432 (db: proposal_platform)
# - Redis on localhost:6379
```

## Conventions
- All settings use `RFP_` env prefix (e.g., `RFP_DATABASE_URL`)
- Agents return dicts; the agentic tool layer auto-fills missing args from `state.results`
- Every response includes `agent_trace` for observability
- Alembic for DB migrations (`alembic/`)
- Tests in `tests/` — run with `pytest`
