# RFP Proposal Platform

## Overview
Domain-agnostic multi-agent RFP platform. FastAPI backend, Streamlit UI, Groq models
(`openai/gpt-oss-120b` frontier, `openai/gpt-oss-20b` fast), Postgres + pgvector, Redis.

## Layout
```
src/app/
  core/          config (RFP_ env prefix), logging, redis client, error mapping
  domain/        domain profiles (YAML in configs/domain_profiles) — all industry/company specifics live here
  llm/           Groq client, LLMService (routing, cache, rate limit, usage), usage reports
  agents/        12 agents; prompts.py lays prompts out static-first for Groq prompt caching
  agentic/       supervisor (fast model), tool registry, plan-execute runner
  orchestration/ endpoint → run_agentic → response (+ token_usage, persistence)
  services/      retrieval, ingestion, coverage (semantic requirement matching), run_store
  ingestion/     JSON normalization, document parsing (PDF/DOCX/MD)
  api/           routers, API-key auth, inbound rate limit
web/             React + TypeScript web app (Vite, Tailwind, Motion); served by FastAPI from web/dist
ui/              legacy Streamlit UI
src/rfp_mistral/ optional legacy LoRA pipeline ([training] extra)
```

## Rules
- Never hardcode industries, vendors, offerings, or section names in code: put them in a profile.
- Every model call goes through `LLMService.complete/complete_json` with `agent=<name>` (routing + usage).
- Keep prompts deterministic and static-first; per-request data goes last.
- Agents raise `LLMServiceError` unless `settings.llm_allow_degraded`; tools turn errors into `ok: False`.
- Responses always include `token_usage` and `agent_trace`.
- Web colors come from tokens in web/src/styles/index.css (dark default, light under [data-theme=light]); never hardcode hex in components.

## Commands
```bash
pip install -e ".[ui,dev]"
alembic upgrade head
uvicorn main:app --app-dir src --reload
cd web && npm run dev       # :5173, proxies /api
cd web && npm run build     # API serves it at /
pytest                       # fakes for Groq and Redis
python scripts/smoke_groq.py # live Groq check
```
